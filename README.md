# Портфоліо UI/UX дизайнера

Проєкт особистого сайту-портфоліо. Зараз вивчаємо середовище розробки та налаштовуємо
процес роботи через GitHub Spec Kit. У `index.html` збережена експериментальна верстка.

## Де що лежить

- `index.html` — поточна тестова сторінка.
- [Constitution](.specify/memory/constitution.md) — правила співпраці, погодження змін і роботи з Git.
- `.specify/templates/` — шаблони документів Spec Kit.
- `.specify/scripts/` — допоміжні скрипти.
- `.specify/workflows/` — опис процесу Spec Kit.
- `.agents/skills/` — інструкції Spec Kit для Codex.
- `specs/` — майбутні специфікації задач; каталог ще не створений.

## Послідовність роботи

1. `constitution` — правила проєкту.
2. `specify` — що потрібно зробити, навіщо та як визначити готовність.
3. `clarify` — уточнення відкритих питань за потреби.
4. `plan` — погоджений технічний спосіб реалізації.
5. `tasks` — послідовні завдання.
6. `analyze` — перевірка узгодженості документів за потреби.
7. `implement` — виконання погоджених завдань.

Структура сайту, технології та вимоги до першої версії ще не затверджені.
Дизайн та адаптивні макети користувач надасть у Figma через MCP.

Попередні початкові пропозиції з `docs/` прибрані з робочої структури;
їх можна відновити з історії Git. Нові погоджені вимоги оформлюватимемо через Spec Kit.
