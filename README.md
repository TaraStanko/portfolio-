# Портфоліо UX/UI дизайнера

Особистий сайт, що поєднує резюме та портфоліо для пошуку роботи й залучення клієнтів.
Основна аудиторія — рекрутери та власники бізнесу. Перша версія буде англійською;
українська версія — у перспективі. Дедлайн — 1 грудня 2026 року.

## Поточний стан

Сесію формування базової документації завершено. Constitution затверджено,
погоджені загальні вимоги збережено у специфікації. Наступний крок — дизайн користувача
та дослідження для визначення структури й складу першої версії.
Технічний план і реалізацію ще не розпочато.

Погоджений напрям — JavaScript із фреймворком. Конкретний фреймворк та бібліотеки
оберемо разом після аналізу дизайну. У index.html збережено експериментальну верстку;
вона не визначає дизайн майбутнього сайту.

## Наступні кроки

1. Користувач готує дизайн для комп'ютера й телефона та копірайт.
2. За результатами досліджень і дизайну визначаємо структуру, кейси та контактну взаємодію.
3. Асистент аналізує макети, ресурси, анімації та можливі 3D-сцени.
4. На етапі plan погоджуємо фреймворк, технічні рішення та підтримувані браузери.
5. Формуємо tasks і після погодження переходимо до implement.

Початкове розміщення планується на GitHub; робоче тлумачення — GitHub Pages.
Адмінпанель та аналітика не потрібні. Контент оновлюємо через код.
Commit, push, merge та публікацію виконуємо в межах явного дозволу користувача.

## Послідовність Spec Kit

constitution → specify → clarify за потреби → plan → tasks → analyze за потреби → implement.

Попередні початкові пропозиції з docs/ доступні в історії Git;
актуальні рішення ведуться у документах Spec Kit.
